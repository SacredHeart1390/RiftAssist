- Use concise Korean. Give fuller reports when requested; avoid repeating settled background.

- Prefer targeted searches, bounded file excerpts, and compact tool results. Reuse verified findings unless changes or time-sensitive facts require another check.
- Do not launch subagents or run tests unless explicitly requested. Do not perform speculative work outside the current task.
- After meaningful progress, update the brief concisely; avoid duplicating the full history across documents.
- Preserve task completeness, source accuracy, and necessary verification while reducing redundant work. Never claim implementation or validation based only on a plan.
