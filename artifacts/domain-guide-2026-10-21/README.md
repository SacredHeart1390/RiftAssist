# 고정 도메인 운영 안내

- 요청: 집 PC 기반 고정 도메인 운영의 단계별 역할 안내와 바탕화면 Word 파일.
- 전달: `리프트어시_고정도메인_운영안내_2026-10-21.docx`, 바탕화면에도 같은 파일 보관.
- 근거: 현재 통합본 관리자·허용 주소 코드, 작업 요약, 2026-10-21 확인한 Cloudflare 공식 안내 5개. 공식 링크는 Word 마지막 페이지에 포함.
- 범위: 설명 작성만. 구매·터널 등록·서비스 설치·앱/관리자/서버 설정 변경·재시작·유료 AI 호출 없음.
- 문서 검토: 숨김 Word COM 읽기 전용 PDF 내보내기 → documents 스킬 render_docx.py에 Word PDF 어댑터와 PDFium 적용 → 최종 5쪽 전체 시각 확인. 초기 빈 페이지·분할·템플릿 제목 밑줄을 수정했다. 앱 테스트는 실행하지 않았다.
- Desktop 복사 후 SHA256 일치 확인. 생성·렌더링 스크립트와 PDF/PNG는 이 폴더의 내부 작업 자료.
