# 통합본 — 작업 위치 안내

2026-10-19. 사용자가 이 통합본을 앞으로의 개발 기준으로 채택했다. 상위 프로젝트 루트의 분리형 앱은 백업으로 계속 보존한다.

- 최신 정정: **초대코드/가입 없이 누구나 URL로 사용하는 공개형 베타**이며 검색 유입도 허용한다. 소수에게 URL을 알리는 것은 접근 자격 제한이 아니다. `CLOSED_BETA_PLAN.md`는 기존 파일명만 유지하고 공개형 설계로 수정했다. 초대 테이블/API는 제외하고 익명 세션으로 제보 소유권을 관리한다. 관리자 인증·남용/비용 제한은 유지한다.
- 사용자는 집 PC 운영을 선호하지만 PC를 꺼도 호스팅비 없이 유지 가능하면 대안을 원한다. 우선 제안은 Render Free + Supabase Free, 집 PC + 안정적 터널/로컬DB는 대안. 무료안에는 기동 지연·저이용량 DB 정지·저장/요청 한도가 있고 OpenAI 사용료는 별도. 검색용 정적 소개 페이지 보완도 설계했다. 계정 생성/앱 변경/네트워크 공개/배포/테스트는 하지 않았다.
- 이용 한도·보유 기간·호스팅은 제안값이다. 다음 구현 순서는 요청 추적/DB → 제보 UI/관리 → 익명 권한·관리자 인증·예산 제한 → 배포 검증 → 공개 URL 안내. 사용자 실행 요청을 받은 범위만 진행한다.

- 보존 원본: 상위 프로젝트 루트의 앱, http://127.0.0.1:3000/.
- 현재 수정 대상: 이 폴더의 앱, http://127.0.0.1:3001/. 실행: 이 폴더에서 `node src/server.js`.
- 2026-10-19 서버 기동 및 브라우저 화면 열림 확인: 3488개 근거 로드, 기존 키/생성 활성화 설정 유지. 프로세스 기록은 이 폴더의 `tmp/local-server.json`. UI에서 유형 탭 없이 질문창이 표시됨. 실제 질문은 제출하지 않았다.
- 질문 탭 제거, 공식 규칙 전체 검색, 대회 맥락에 따른 근거 우선순위, 필요한 조건만 확인하는 프롬프트 적용. 구현 상세는 README의 ‘원본과 복사본’ 참고.
- `.env`와 기존 색인/번역 캐시를 원본에서 복사했다. 비밀키를 출력하거나 배포하지 않는다. 원본과 같은 API 과금 계정을 사용하며 이후 로그·번역 캐시는 독립적이다.
- 실제 질문·유료 호출·테스트는 통합 수정 및 베타 설계 중 하지 않았다. 개발은 이 폴더에서 계속하며 백업 원본에 덮어쓰지 않는다.
- 전체 프로젝트 배경은 상위 프로젝트의 WORKING_BRIEF.md를 참조한다. sources/와 저지 검수21문항은 수정하지 않았다.
