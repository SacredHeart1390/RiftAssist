# 리프트어시 다음 단계 실행 준비

작성: 2026-10-20 · 상태: **설계 완료, 구현·배포 전**

현재 베타의 코드·설정·자료·프로세스는 변경하지 않았다. 이번 작업은 코드/저장 기록의 읽기 전용 조사, 검색 함수의 격리 분석, 공식 문서 확인과 준비 문서 작성이다. 테스트 묶음과 유료 AI 호출은 실행하지 않았다. 루트 백업과 sources/는 보존한다.

## 준비한 다섯 항목

| 요구 | 준비 문서 | 적용 시 핵심 |
|---|---|---|
| 네 자료원 자동 갱신, 자료·앱 교체 | [01-data-updates.md](01-data-updates.md) | 출처 발견 → 검증 → 버전 묶음 교체. 집 PC에서는 상시 프록시와 앱 2개로 전환 |
| PC를 꺼도 운영 | [02-cloudflare-hosting.md](02-cloudflare-hosting.md) | Workers + D1 + R2, 관리자 Access, 수집 작업 별도 실행 |
| 답변 끝 반복 고지 정리 | [03-answer-policy.md](03-answer-policy.md) | 공통 안내는 하단 한 곳, 판정에 영향을 주는 불확실성만 답변에 표시 |
| 점멸 4장 사례 오류 | [04-retrieval-diagnosis.md](04-retrieval-diagnosis.md) | 수량·덱 구성 의도 추출, 기본 규칙/예외/대회 처리의 연결 검색 |
| 비용과 광고 | [05-cost-and-ads.md](05-cost-and-ads.md) | 실제 토큰 표본 + 보수적 예산, 검수된 설명 페이지에 작은 광고 1개 |

기계가 다시 읽을 준비값은 `implementation-contracts.json`, 비용 입력값은 `cost-assumptions.json`에 둔다. **실행 파일이나 운영 설정이 아니며 앱에서 읽지 않는다.**

## 권장 적용 순서

1. 원문 추출 무결성·검색 품질·반복 고지 수정. 점멸 질문은 검색 누락이며, 추가로 대회 PDF의 참조 번호를 새 조항으로 읽어 기존 내용을 덮어쓰는 결함도 확인했다.
2. 자료를 읽는 공통 인터페이스와 버전/출처 추적을 분리한다.
3. 집 PC를 당분간 유지하면 자동 갱신·상시 프록시를 구현한다. 곧 클라우드로 옮긴다면 Windows 전용 전환기는 생략하고 공통 자료 계층을 클라우드에 먼저 적용한다.
4. 클라우드 별도 시험 주소에서 기능 확인 후 공개 주소를 전환한다.
5. 비용 기록이 쌓이고 자료 사용 범위·광고 심사가 정리되면 광고를 켠다.

## 나중에 사용할 지시와 작업 범위

- **“이제 자동 데이터 갱신 시스템을 적용시키자”**: 01과 04의 자료 구조를 기준으로 구현을 시작한다. 새 출처 발견/보류/교체/되돌리기와 관리자 화면을 연결한다. 리프트나루 제공 경로가 없으면 수동 파일 가져오기까지 연결하고 자동 수집 완료로 보고하지 않는다.
- **“그 호스팅 서버 어쩌구를 구현해서 적용시키자”**: 02를 기준으로 별도 Cloudflare 실행부를 작성하고, 계정의 실제 이용 가능 기능/요금과 로그인 상태를 확인한다. 구현 후 필요한 계정 연결·유료 플랜·공개 전환을 구체적으로 진행한다.
- **“답변 고지와 검색 오류부터 적용하자”**: 03·04부터 적용한다. 현재의 범용 고지를 없애면서 근거 미확보까지 숨기지 않는다.
- **“광고를 적용하자”**: 05의 승인된 공개 설명 페이지에만 수동 슬롯 1개를 연결한다. AdSense 승인 전에는 광고 요청 자체를 보내지 않는다.

위 문구는 자동 예약이나 완료 약속이 아니다. **다음 요청에서 설계를 다시 만드는 시간을 줄이기 위한 인수인계**이며, 실제 코드 작성과 확인은 그때 한다. 사람 검수 및 유료 API 평가가 필요하면 별도로 범위를 정한다.

## 사용자가 준비할 외부 항목

- 클라우드 적용: 본인 Cloudflare 계정 로그인. 권장안은 Workers Paid 월 $5 기본요금이며 실제 가입/결제는 미실행. 처음은 workers.dev 주소 사용 가능, 도메인은 나중에 구매할 수 있다.
- 카드 자동화: 리프트나루에 데이터 사용 범위와 API/정기 JSON 제공 여부 문의. 카드 이름·본문·이미지·번역·AI 입력·광고 포함 서비스·표기 조건을 함께 확인한다. 차단 우회는 계획에 포함하지 않는다.
- 공개 전환: 현재 trycloudflare.com 주소를 Cloudflare 호스팅 주소로 그대로 이전할 수 있다고 가정하지 않는다. 새 주소 안내가 필요하다.
- 광고: 본인 AdSense 계정·사이트 승인·정산 설정. 수익은 승인과 실제 트래픽에 따라 달라진다.

## 재개할 때 먼저 할 일

1. WORKING_BRIEF와 이 문서만 먼저 읽고 작업 범위를 선택한다.
2. 현재 서버/터널/파일 변경 여부와 최신 자료 버전을 짧게 확인한다. 이번 조사 시점과 운영 시점은 구분한다.
3. 통합본 작업용 복사 또는 버전 관리 스냅샷을 만들고 루트 백업을 보존한다. 키·운영 DB를 공개 저장소에 넣지 않는다.
4. 계정/자료 제공 경로가 없는 항목은 준비된 대체 경로로 진행한다. 자동 갱신 스케줄은 앱 운영 기능으로 구현하며 이 대화의 예약 자동화로 대체하지 않는다.
5. 단계별 변경·확인 결과·남은 제한을 기록한다. 현재 계획을 구현 완료로 표시하지 않는다.
