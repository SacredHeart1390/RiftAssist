# 비용·광고 운영 계획

기준일: 2026-10-20. 가격은 공식 공개 표 확인, 사용량은 로컬 성공 호출 기록의 작은 표본, 미래 트래픽·환율·광고 RPM은 **계산을 위한 가정**이다. 계정 청구서/실제 크레딧 잔액을 조회한 결과가 아니다. 가입·구매·광고 신청·API 설정 변경은 하지 않았다.

## 1. 현재 모델과 비용

앱은 `gpt-6-luna`를 사용한다. 현재 공식 Standard 가격은 입력100만 토큰 $0.10, 출력100만 토큰 $0.50. 캐시 입력은 $0.01이고 별도 캐시 쓰기 가격도 있으므로 아래에서는 캐시 할인/쓰기 작업을 가정하지 않는다. [공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-6-luna)

```text
API 비용 = 입력 토큰 × 0.10 / 1,000,000
         + 출력 토큰 × 0.50 / 1,000,000
```

| 이번 조사 시 기록된 성공 호출 | 건수 | 전체 입력 | 전체 출력 | 위 단가의 단순 환산 |
|---|---:|---:|---:|---:|
| 답변 | 11 | 26,142 | 7,112 | $0.0061702 |
| 근거 번역 | 7 | 3,236 | 1,736 | $0.0011916 |
| 합계 | 18 | 29,378 | 8,848 | $0.0073618 |

환율을 $1=1,400원으로 가정하면 전체 약10.3원, 답변11건으로 나누면 번역 포함 약0.94원/질문이다. **근거 부족의 짧은 답변이 포함된 표본**이므로 정상 장문 판정의 평균 비용이라고 단정하지 않는다. 이전 기록에 없는 호출·실패 과금·사진·캐시 처리·다른 프로젝트 비용 등은 이 집계에 포함되지 않는다. 개발용 ChatGPT/Codex 사용 한도와 서비스의 OpenAI API 비용은 별개다.

## 2. 운영 예산에 쓸 가정

- 답변1회: 입력5,000 + 출력1,000토큰.
- 질문당 새 번역 평균0.5회: 번역1회당 입력1,000 + 출력500토큰. 이미 번역된 근거는 캐시 재사용.
- 합계: 질문당 입력5,500 + 출력1,250 = 6,750토큰, **$0.001175**.
- 계획 여유20% 포함: **$0.00141/질문**, 약1.97원/질문.
- 환율: 계산용 $1=1,400원. 실시간 환율 예측이 아니다.
- 도메인: 일반 `.com`의 연간 예산 **$15**, 월 환산$1.25. 조사 시 Porkbun 일반 `.com` 표는 등록/갱신/이전 각각$11.08이지만 업체·시점·이름에 따라 다르다. `riftassistant.com` 확보 가능 여부·프리미엄 여부는 확인하지 않았다. [도메인 가격표](https://porkbun.com/products/domains)
- 클라우드: Workers Paid 기본$5/월 + 저장/갱신/부가 작업 예비비$2/월. 도메인 포함 고정 예산 **$8.25/월**. $2는 업체 확정요금이 아니라 예비비다. [Workers 요금](https://developers.cloudflare.com/workers/platform/pricing/)

**사진 입력, 추가 모델 호출/고급 모델, 대규모 최초 수집, 포함량 초과, 세금·환전/카드 수수료는 별도다.** 현재 기본 출력 상한4096토큰과 평균 출력1000은 다르며, 복잡한 질문이 많으면 실제 비용이 상승한다. 본문이 길어 총 토큰 소비가2배가 되면 표의 API 부분이2배가 되는 식으로 계산한다.

## 3. 월 운영 규모별 계산

| 월 AI 질문 | 기본 예상 토큰(번역 포함) | API 예산(20% 여유 포함) | 호스팅·도메인·예비비 포함 | 원화 환산 |
|---:|---:|---:|---:|---:|
| 1,000 | 675만 | $1.41 | $9.66 | 약13,524원 |
| 3,000 | 2,025만 | $4.23 | $12.48 | 약17,472원 |
| 10,000 | 6,750만 | $14.10 | $22.35 | 약31,290원 |

현재는 답변30회/일 제한이라 30일에 최대 약900회다. 위1,000회 이상 시나리오는 **향후 한도를 늘리는 경우**이며 이번에 한도를 올리지 않았다. 번역도 별도30회/일이므로 질문 수만으로 토큰을 계산하지 않는다.

집 PC+임시 주소를 유지하면 호스팅·도메인 비용을 줄일 수 있지만 전기와 PC 사용 부담이 남는다. 예를 들어 추가 소비40W ×24시간×30일 =28.8kWh이며, 계산용 단가200원/kWh를 가정하면 약5,760원이다. 실제 전기요금·누진 구간을 반영한 견적이 아니므로 전력계와 청구서로 교체해야 한다. PC를 원래 꺼두었을 경우와 원래 켜두었을 경우의 추가 비용도 다르다.

## 4. AdSense를 바로 붙일 수 있는가

광고 연동 자체는 가능하지만, **현재처럼 매번 생성되는 미검수 AI 답변 화면에 바로 넣는 계획은 권하지 않는다.** Google은 수동 검토/편집 없는 자동 생성 콘텐츠의 광고와 콘텐츠 없는/가치가 낮은 화면의 광고를 제한한다. 승인된 계정과 정책을 만족하는 고유 콘텐츠가 필요하며, 신청하면 반드시 승인된다는 보장은 없다. [자동 생성 콘텐츠 관련 정책](https://support.google.com/publisherpolicies/answer/11112688?hl=en), [참여 요건](https://support.google.com/adsense/answer/9724?hl=en)

### 추천 배치

1. 질문·답변 화면, 로딩·오류 화면, 제보·관리 화면에는 광고를 넣지 않는다.
2. 운영자/저지가 검수한 공개 ‘룰 설명 / 실제 사례 해설 / 업데이트 안내’ 페이지를 별도로 만든다. 외부 Q&A를 그대로 복제한 페이지 대신 직접 작성한 설명과 비교를 제공한다.
3. 그런 페이지의 본문 아래에 작은 반응형 수동 광고1개만 둔다. ‘광고’ 표시와 공간을 확보하고 질문 버튼·드롭다운·카드 이미지 옆에는 두지 않는다.
4. 전면/앵커/자동 삽입 광고, 영상, 광고 시청 후 질문 허용 방식, 자동 새로고침을 쓰지 않는다. 광고 차단을 이유로 이용을 막지 않는다.
5. 오류가 나거나 광고가 안 채워져도 앱은 정상 사용 가능하게 한다. 공통 질문 화면에 광고 스크립트를 전역 삽입하지 않는다.

Google은 오클릭을 유발하는 배치와 클릭 권유를 금지한다. ‘운영비를 위해 광고를 눌러 주세요’ 같은 문구도 쓰지 않는다. [배치 정책](https://support.google.com/adsense/answer/1346295?hl=en)

외부 원문을 거의 그대로 재게시한 화면은 별도 문제이므로 승인된 설명 콘텐츠로 구성한다. [복제 콘텐츠 정책](https://support.google.com/publisherpolicies/answer/11190248?hl=en)

## 5. 광고 수입: 시장 예측이 아닌 민감도 계산

계산은 **게시자가 받는 페이지 RPM**을 사용한다.

`예상 수입 = 광고를 허용한 페이지의 월 조회수 / 1,000 × 페이지 RPM`

페이지 RPM300원/1,000원/2,000원은 이 사이트에서 측정한 값이나 보장된 국내 단가가 아니다. 수익률을 비교하기 위한 세 가정이다. 실제로는 광고 미게재·차단·방문 지역·계절·심사·무효 트래픽 등에 따라0원일 수도 있다. 실제 페이지 RPM에는 수익 분배가 반영되므로 68% 같은 비율을 다시 곱하지 않는다. [RPM 계산](https://support.google.com/adsense/answer/190515?hl=en), [게시자 수익 분배](https://support.google.com/adsense/answer/180195?hl=en)

**AI 질문 수와 광고 페이지 조회수는 별개다.** 아래 조회수는 검수된 공개 설명 페이지를 방문한다고 따로 가정한 값이다.

| 월 질문 | 광고 허용 페이지 조회 가정 | 전체 비용 | RPM300원 수입 | RPM1,000원 수입 | RPM2,000원 수입 | 중간 가정에서 운영자 부담 |
|---:|---:|---:|---:|---:|---:|---:|
| 1,000 | 500 | 13,524원 | 150원 | 500원 | 1,000원 | 13,024원 |
| 3,000 | 2,000 | 17,472원 | 600원 | 2,000원 | 4,000원 | 15,472원 |
| 10,000 | 8,000 | 31,290원 | 2,400원 | 8,000원 | 16,000원 | 23,290원 |

예를 들어13,524원 비용을 RPM1,000원으로 모두 충당하려면 광고 가능한 페이지가 월13,524회 조회되어야 한다. **이를 목표로 광고를 늘릴 필요는 없다.** 초기 소규모 베타에서는 광고 수입을0원으로 잡고 감당 가능한 연구비로 운영하는 편이 현실적이다.

## 6. 흑자를 목표로 하지 않는 운영안

- 초기: 광고0, 주간 API 토큰·비용·일평균 질문·오류율부터 기록. 기본 한도를 유지한다.
- 다음: 직접 검수한 설명 페이지와 고정 주소를 마련하고 출처 사용 조건/광고 심사를 정리한 뒤1개 슬롯만 적용한다.
- 월 연구비 예산 제안: 우선2만원 안팎을 출발점으로 삼고 사용자 의사에 따라 정한다. 확정/적용된 예산이 아니다. 실제 월1만 질문 수준에서는 이 예산을 넘을 수 있으므로 한도와 예산을 함께 조정한다.
- 목표: 운영비의 일부(예:25~50%)만 보조, 나머지는 연구비. 흑자가 지속되면 노출 페이지 수/광고 기간을 줄이거나 광고를 끈다. 수입이 불규칙하므로 매달 정확히 손익0으로 맞출 수는 없다.
- 광고 승인 전·미지급 상태의 예상 수입으로 API 한도를 늘리지 않는다. 정산 금액과 예상 수익도 구분한다.
- 신고와 비용 요약을 함께 보고 ‘자료 검색 개선/번역 재사용’부터 최적화한다. 무조건 저렴한 답만 만들거나 모든 질문을 고급 모델로 보내지 않는다.

## 7. 구현할 비용 관리

관리 화면: 오늘/이번 달 답변·번역 호출, 입력·출력 토큰, 모델/가격표 버전별 추정 비용, 클라우드 실제 사용량, 광고 정산액, 도메인 연간 비용을 나눠 표시한다. 소액 값을0원으로 반올림해 숨기지 않는다.

서버: 동시 예약을 포함한 질문 한도 + 월 API 예산 + 입력 길이/출력 토큰 상한. 실패/중복 호출을 식별하고 원문 번역 캐시를 재사용한다. 같은 규칙 개정으로 전체 카드와 Q&A를 매번 모델에 보내지 않는다. API 비용 제한은 앱에서 시행하며 외부 콘솔의 예산 알림만 강제 중단 장치로 가정하지 않는다. 호스팅 초과요금까지 완벽하게 차단하는 장치는 별도로 설계해야 한다.

## 8. 광고 전 준비 사항

- 고정 주소/직접 작성·검수한 공개 콘텐츠/운영자 문의/개인정보 안내를 갖춘 뒤 AdSense에 신청한다.
- 사용자 질문과 사진을 공개 설명 페이지나 광고 사업자에게 자동 공개하지 않는다. 실제 질문을 공개 사례로 쓰려면 별도 공개 권한과 비식별 검토가 필요하다.
- 지역별 광고 동의가 필요한 경우 별도 기능을 적용한다. 예를 들어 EEA/영국/스위스 대상 광고는 Google 인증 CMP 요건을 확인해야 한다. 질문 제출 자체를 광고 추적 동의로 간주하지 않는다. [Google 동의 요건](https://support.google.com/adsense/answer/13554116?hl=en)
- Riot 팬 프로젝트 정책은 조건부 수동 광고 수익을 허용하지만 제3자 자료 사용이나 모든 형태의 앱 배포를 포괄 승인하는 것은 아니다. 팬 프로젝트 고지와 자료 공급자 표기 조건을 별도로 충족한다. [Riot 정책](https://www.riotgames.com/en/legal)
- 리프트나루에 문의할 항목: 캐시/전체 색인/갱신 API, 한영 이름·본문·이미지 재사용, OpenAI 입력 전송, 무료 이용+소량 광고, 출처 표기 위치, 호출 제한, 정정·삭제 반영. 이번에 이메일을 보내지 않았다.

실행 위치 제안: `public/guides/` 또는 대응 콘텐츠 라우트, `public/ads.js`의 허용 페이지 전용 로딩, 서버의 광고 활성/심사 상태 설정, 관리자 비용 화면. 광고는 기본 false로 작성하고 승인된 사이트/슬롯 ID가 있을 때만 활성화한다. 구체적인 HTML 광고 코드와 사이트 ID는 승인 후 연결한다.
