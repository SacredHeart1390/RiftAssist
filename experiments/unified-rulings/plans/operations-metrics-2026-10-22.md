# 운영 현황과 비용 집계

2026-10-22. 사용자 계정 조작 없이 진행할 개발 범위. Cloudflare 계정/구매/터널/예산 변경은 하지 않는다.

## 이번에 구현하는 범위

- 관리 화면의 기존 인증 API만 사용하여 앱 버전, 진행 중 HTTP 요청, 당일 AI 호출 시도, 전체 보관 제보 중 미해결 수, 규칙/Q&A 확인 시각과 수집량, 수동 카드 갱신 상태를 표시한다.
- 답변/번역별 일일 사용량·남은 호출 수·토큰·미확인 입력 사용량을 표시한다. 80% 사용/한도 도달, 수집기 기록 3분 경과, 자료 확인 주기 + 30분 경과, 수집 오류를 관리자 화면에 표시한다. 경고만 표시하며 서비스/설정/자료를 자동 변경하지 않는다.
- 상태10초, 자료/제보60초 조회. 숨겨진 탭에서는 멈추고 복귀 시 갱신한다. 인증 만료 시 중지하며 읽기 요청15초 제한을 둔다. 화면을 닫으면 이 조회도 중단되므로 상시 장애 감시나 외부 알림 기능으로 설명하지 않는다.
- 조회 실패 시 이전 값과 조회 실패를 함께 표시한다. 날짜는 KST 고정. 자동 갱신 시 자료/앱 선택값과 제보 메모를 보존한다. 자료 선택이나 활성 버전 변경 시 검토 확인란을 해제한다.
- 운영 요약 JSON은 집계/상태만 선택하여 내보낸다. 질문·답변·제보 본문과 인증정보는 넣지 않는다. 제보 상세 내보내기는 기존 기능 그대로다.
- `manager-ui/` 정적 파일만 교체하여 기존 관리자/게이트웨이/터널/앱을 유지한다. 기존 화면은 새로고침 후 반영된다.

## 기존 기록으로 표시할 수 없는 항목

현재 `/api/status`는 당일 호출 종류별 횟수와 토큰, 보관 제보 상태별 개수를 제공한다. 질문 수·성공률·처리시간·기간별 집계·원화/달러 비용은 이 응답에서 얻을 수 없다. 호출 시도 수를 질문 수나 정답률로 바꾸어 표시하지 않는다.

`calls` 테이블에는 모델/실제 응답 모델/캐시 입력/단가 기준 정보가 없다. `usageUnknown` 집계는 입력 토큰 NULL만 센다. 따라서 모든 과금 누락을 검출하거나 전체 비용을 계산한 것으로 표시할 수 없다. 현행 기록의 한계는 UI와 내보내기에 반영한다.

## 다음 구현 묶음과 반영 조건

1. **조회용 집계 API**: 관리자 인증 아래 기간별 요청 상태·생성/번역·오류·미확인 사용량·처리시간 집계 추가. 날짜 범위는 KST 기준. 기존 30일 보존 한계 및 월초 기록 누락 여부를 응답에 포함. 사용자 본문을 브라우저에 보내어 집계하지 않는다.
2. **호출별 과금 메타데이터**: 모델 요청명/응답명, 입력·캐시 입력·출력 토큰, 상태, 오류, 요청 종류, 가격표 버전, 호출 시작·완료 시각을 nullable 필드로 보존한다. 기존 기록은 미확인으로 유지하며 현재 모델로 일괄 소급하지 않는다. AI 내부 사고 과정은 수집하지 않는다.
3. **추정 비용**: 구현 시 공식 가격표를 확인하고 기준일·통화·가격 적용 조건을 저장. 단가나 사용량이 없는 호출은 미산정 수에 포함하고 0원으로 계산하지 않는다. 응답에서 확인된 토큰을 공식 과금 명세에 맞추어 계산하고 중복 합산을 방지한다. 청구서와 차이가 생길 수 있음을 표시한다.
4. **보존과 집계**: 원본 로그30일 정리와 월별 누적 집계가 충돌하지 않도록 익명 일별 집계를 먼저 확정한다. 진행 중/사용량 미확인 호출은 확정 집계와 분리하고 지연 정산을 고려한다. 추가 보존 기간은 명시적인 운영 정책으로 정한다.
5. **월 예산**: 운영자가 금액을 정하면 비용 예약/정산/동시 요청을 고려한 제한을 연결한다. 이번 작업에서는 임의 예산이나 새 결제 제한을 설정하지 않는다. 앱 추정치가 API 공급자의 확정 청구 상한인 것으로 설명하지 않는다.

관리 API는 시작 시 로드되므로 이 묶음에는 관리자 프로그램 변경이 필요하다. 현재 구조에서 관리자 재시작은 공개 게이트웨이/터널에도 영향을 줄 수 있다. 다음 점검 시간에 적용하거나, 관리 프로세스 분리 설계 후 반영한다. 서비스 중단을 피하려고 별도 공개 통계 API나 우회 인증 서버를 만들지 않는다.

## 후속 개발 순서

운영 요약 실사용 → 기간별 집계/과금 메타데이터 → 운영자 예산 지정 → 예산 제한 → 장애 복구/백업. 고정 도메인은 사용자 준비 완료 시 병행한다. 사진·무인 카드 수집·광고·기존 평가문항은 이번 작업에 포함하지 않는다.
