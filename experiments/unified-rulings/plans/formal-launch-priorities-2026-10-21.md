# 정식 운영까지의 우선순위

2026-10-21 v0.1.4 적용 이후 계획. 이번 문서는 계획이며 구현·설정 변경·테스트·구매·예약 작업을 실행하지 않는다.

## 유지하는 결정

- 집 PC 운영, 가입/초대코드 없는 공개 서비스. 관리 화면은 본인 전용.
- 판정 피드백은 베타 이용자의 제보로 받는다. 기존 저지 검수/기본형21문항 계획은 종료한다.
- 사진 질문은 중지, 카드 갱신은 사용자 요청 시 진행한다. 규칙/Q&A 자동 갱신은 유지한다.
- 새 공개 화면 정보 패널을 추가하지 않고 운영 정보를 관리 화면에 모은다.

## 순서와 완료 기준

1. **운영 현황·비용 집계**: 현재 일별 호출/토큰 기록을 바탕으로 질문 수·생성 성공·처리 실패·근거 부족·처리시간·답변/번역 사용량·추정 비용·미해결 제보·자료 갱신 실패를 관리 화면에서 확인. 생성 성공을 판정 정답률로 표시하지 않는다. 가격은 구현 시 공식 표로 다시 확인하고 가격 기준일/미확인 사용량을 구분한다. 실제 청구액과 대조할 수 있어야 완료.
2. **사용 예산·요청 제한 보강**: 기존 일일 횟수/동시 제한을 유지하면서 운영자가 정한 월 예산과 짧은 시간 반복 요청 제한을 설계·적용. 새 유료 호출 전 예상 최대 비용을 예약하고 사용량을 정산한다. 진행 중 호출과 사용량 미확인 호출도 고려. 추정 비용 차단을 공급자 청구액의 확정 상한으로 설명하지 않는다. 초과 시 안내와 제보 기능은 유지.
3. **장애 복구·백업·갱신 실패 대응**: DB/복호화 키/설정/앱·자료 버전의 복구 방법, 주기 백업·보존 정리·별도 매체 사본, 프로세스 종료 감지와 재기동, PC 재부팅 후 시작 정책을 준비. 수동 중지 상태는 자동 재기동과 구분한다. 전체 PC/인터넷 장애는 집 PC 내부 감지만으로 해결되지 않는다. 복구 확인은 사용자 요청 시 격리 환경에서 수행. PC 재시작 검증은 별도 시간에 진행.
4. **공개 운영 안내·자료 이용 정리**: 운영자 문의/삭제 요청 경로, 저장 및 외부 전송 안내, 서비스 범위/자료 출처/갱신 정책/공지 정리. 리프트나루 및 외부 자료의 이용·번역·재배포 범위와 필요한 출처 표시를 확인. 외부 문의는 사용자 발송 요청 전 보내지 않는다. 권한이 있다고 가정하지 않는다. 운영자가 연락/동의해야 하므로 앞 단계와 병행 가능.
5. **고정 도메인·지속 연결**: 도메인 가용성/등록·갱신 비용 확인 → 사용자 구매/계정 준비 → 정식 Cloudflare Tunnel·고정 HTTPS 주소 연결. 집 PC 구동은 유지한다. 기존 베타 연결을 유지하며 새 주소를 먼저 준비하고 전환한다. 관리자 주소를 공개 터널에 연결하지 않는다. 재연결 뒤 주소 유지가 완료 기준.
6. **정식 전환 점검·운영 범위 결정**: 외부 PC/모바일에서 질문/카드 선택/근거 열기/제보→관리 수신/사진 차단/한도 안내/관리자 접근 차단/복구 경로를 필요한 범위에서 확인. 이는 기존 기본형 판정 문항 평가를 재개하는 일이 아니다. 중대한 미해결 접속·저장·자료 유실 문제를 정리하고 허용 동시 이용량·운영 시간·공지 방법을 정한 후 공개 범위를 확대.

### 제보가 들어왔을 때

서버 중단·질문/제보 저장 실패·비용 누수는 위 계획보다 먼저 대응한다. 판정 관련 제보는 당시 질문/자료 버전/인용을 확인하여 원인을 구분하고 수정 이력을 남긴다. 현재 보고된 문제가 없다는 상태와 정답률 검증 결과를 혼동하지 않는다.

## 가장 가까운 개발 묶음

2026-10-22 진행: 기존 API 기반 운영 요약·당일 호출/남은 한도·갱신 이상 안내·요약 내보내기를 관리 정적 화면에 무재시작 반영했다. 기간별 질문 통계/처리시간/비용 집계는 아직 미구현이다. 다음 구현과 반영 제약은 `operations-metrics-2026-10-22.md`를 따른다.

관리자 전용 운영 요약 + 기간별 사용량/추정 비용 표시부터 진행한다. 기존 저장 기록을 집계하여 추가 생성 AI 호출을 발생시키지 않는다. 월 예산 차단은 집계 후 운영자가 예산을 정하면 연결한다. 초기에는 이 화면을 개발하는 것과 알림/예약 자동화를 실제로 켜는 것을 구분한다.

## 정식 출시 이후로 미룰 항목

- 클라우드 이전: PC를 끄고 운영할 필요, 부하/장애 부담이 생길 때 재검토.
- 광고: 고정 주소·실제 비용/트래픽·광고 게재 조건을 확인한 다음. 최초 출시 필수 항목 아님.
- 사진 질문과 무인 카드 수집: 별도 재개 요청 전 보류.
- 로그인/사용자 기록/추가 화면 장식: 현재 요구에서 추가하지 않는다.

## 주소 계획 근거

Cloudflare 공식 문서는 Quick Tunnel을 테스트/개발용으로 설명하며, 정식 트래픽과 고정 호스트명에는 Cloudflare Tunnel 구성을 안내한다. 임시 호스트명은 새 터널을 만들 때 바뀐다. 2026-10-21 확인: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
