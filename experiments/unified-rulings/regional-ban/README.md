# 지역별 금지 판정 실험 — 미연결

2026-11-14 공식 자료를 기준으로 한 별도 프로토타입이다. 현재 앱, API, 사용자 화면, 운영 서버와 연결하지 않았다. AI 무호출 질의, 카드 카탈로그 ID/재인쇄 매칭, 한국 출시일, 대회별 규정, 과거 전체 이력, 6시간 감시·변경 검증 및 승인, 단위/서버/브라우저 회귀와 배포 준비가 남아 있다. 기존 동작을 대체하지 않는다.

`node --test experiments/unified-rulings/regional-ban/decision.test.cjs`로 격리 검증한다. 출처와 시행 예정일은 events.json에 기록한다. 서버 시계와 사용자가 지정한 대회 지역 날짜를 혼동하지 않도록 날짜는 명시적으로 받는다. 출처 범위 밖의 날짜와 형식·대회 규정은 `unknown`이며 사용 가능 여부는 금지 여부와 분리해 `unknown`으로 둔다.

글로벌 9월 18일 이전과 한국 11월 23일 이전 이력은 확인 전 보류한다. 한국의 스피릿포지드 출시일은 미확정으로 보관하고 12월 5~6일 대회 뒤에 출시된다는 공식 공지에 따라 이후 날짜를 추정하지 않는다. 출처 변경 감지와 검증되지 않은 최신화가 구현되기 전에는 운영 판정에 사용하지 않는다.
