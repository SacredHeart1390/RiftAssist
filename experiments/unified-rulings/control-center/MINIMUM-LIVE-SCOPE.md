# v0.2.0 카드 포함 출시 범위

2026-11-10 사용자 정정이 우선한다. v020은 기존 카드 DB/기능과 개선사항을 함께 출시한다. **카드 없는 rules-only 서비스로 축소하지 않는다.** [실제 조사·복원 경로·권리 경계](LEGACY-CARD-LAUNCH.md)가 현재 기준이다.

| 기능 | v020 출시 목표 |
|---|---|
| 카드 자료 | 기존 schemaVersion1 cards.json과 ID/영문/한국어/능력치/출처/버전 전체 보존 |
| 카드 검색·선택·관련 판정 | 검토된 legacy snapshot의 legacy-reviewed 경로 사용. API 키 필수 아님 |
| AI·한국어·이미지 | 공개/모델 입력/한국어/이미지 권한 구분. 미확인 범위는 차단하고 임의 허가하지 않음 |
| 규칙·사례 | 원본 보존. 제3자 사례/외부 검색/번역은 별도 허가 범위에 따라 표시/전송 |
| 질문·제보·관리·Control Center | 기존 운영 schema/키/기록과 버전 개선 유지, 정상 관리자 인증 유지 |
| 배포 | START-RELEASE.cmd → A 무중단 설치 → C 한 번 정지/backup/독립 restore/단독 시작/조건부 복귀 |
| Riot 공식 API | v030 개발 대상. v020 런타임의 필수 의존성에서 제외 |
| SEO | v100 전까지 noindex |

minimum-release.js는 이전 개발 시험/회귀를 위해 보존한다. 운영 후보로 자동 선택하지 않으며 v020 출시 검사/단일 키트는 카드 포함 legacy 후보를 요구한다. 기존 카드를 합성 카드로 교체하지 않는다. 실제 자료는 Git/CI에 넣지 않는다.

API 승인과 자료 이용 허가는 다르다. API 없이 실행 가능해도 기존 Riot/RiftNaru/번역/이미지/사례의 권리 검토, 개인정보, 실제 백업·복구/운영 승인은 필요하다. 공식 정책 적용을 무시하거나 권리를 임의 승인하지 않는다. 추가 VM·Control Center 배포 UI·상시 브로커는 필수 조건이 아니다.
