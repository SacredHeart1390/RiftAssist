# UI 간소화 패치 — 2026-10-21

## 적용

- 운영 앱 v0.1.3, UI 수정 `simplify-tab-2b`. 관리 프로그램·앱·터널 중지/재시작 없이 정적 파일만 교체했다.
- 스크린샷에 표시된 현재 데이터 상태, 설계 원칙, 예시 질문, 질문 옆 도움말, 카드 사용법/수집 날짜, 옆쪽 개인정보 안내를 제거했다. 출처 링크, 주요 보관 안내, 하단 오류 고지, 오류 제보는 유지했다.
- 카드 후보는 방향키로 이동하고 Tab으로 선택한다. Enter는 줄바꿈, Shift+Tab과 후보를 고르지 않은 Tab은 기본 포커스 이동이다. 한글 조합 보호와 포인터 선택 코드는 유지했다.
- 입력/본문/버튼 글씨를 1~2px 확대했다. 입력창과 카드 강조 레이어의 글자 크기를 일치시켰고 모바일 글자 수 표시의 줄바꿈을 막았다.
- 개발 원본 `public/`과 운영 `releases/v0.1.3/public/`에 같은 파일을 반영했다. `app-ui2.js`, `card-composer-ui2.js`, `styles-ui2.css?v=2b`를 사용한다. 서비스워커 캐시는 `riftassi-v0.1.3-ui2b`다.
- 릴리스 manifest에 새 파일 해시와 UI 수정 식별자를 기록했다. 서버 버전 표시는 v0.1.3을 유지한다.

## 실제 확인

- 새 JS 두 파일의 문법 검사 통과.
- 공개 페이지: 제거 대상 없음, 출처 링크 4개/오류 고지 유지, 질문 버튼 활성 상태 정상.
- `포로` 검색 후 방향키·Tab으로 `포로치기` 선택: 카드 연결/강조 1개, 입력창 포커스 유지.
- Enter: 카드 선택 없이 `포로\n`. Shift+Tab/선택하지 않은 Tab의 기본 이동 확인.
- 영어 전환 정상, 한국어로 복원. 데스크톱 및 390px 브라우저 화면에 가로 넘침 없음. 모바일 글자 수 한 줄 표시 확인.
- 브라우저 오류/경고 로그 없음. 유료 질문 생성은 호출하지 않았다. 실물 휴대폰·한글 IME 장치 테스트와 AI 답변 정확도 검수는 이번 확인 범위가 아니다.
- 마지막 로컬 서버 확인 2026-10-21 16:37 KST: 앱 실행 중, 관리자 오류 없음. 수정 파일 5개 HTTP200, 운영 응답/디스크 파일/개발 원본/manifest 해시 모두 일치.
- 상세: `checks.json`, `server-checks.json`, `desktop.jpg`, `mobile.jpg`.

## 새 화면 표시와 복구

- 사용자는 페이지를 새로고침한다. 기존 서비스워커가 남은 경우 한 번 더 새로고침하거나 Ctrl+F5를 사용한다. 작성 중인 질문을 강제로 새로고침시키지는 않았다.
- 변경 전 HTML/서비스워커/manifest는 `backups/ui-simplify-2026-10-21/`에 경로별 보관했다. 이전 r2 스크립트와 스타일은 삭제하지 않았다.
- 복구 필요 시 백업의 각 파일을 대응하는 원래 위치로 되돌리고 새 서비스워커 캐시 이름을 지정해야 한다. 복구 후에도 강제 서버 재시작은 필요하지 않다.
- 루트 백업 앱, sources/, API 키, AI 모델, 데이터베이스와 자동 자료 갱신 설정은 수정하지 않았다.
- 카드 원격 자동 수집은 사용자 결정대로 보류하고, 신규 카드 소식을 알려줄 때 갱신하는 방향으로 진행한다.
