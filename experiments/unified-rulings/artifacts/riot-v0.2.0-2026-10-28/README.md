# RiftAssist v0.2.0 분리 작업

2026-10-28 KST. 개발 브랜치: `feature/riot-api-v0.2`. 운영 v0.1.7은 저장소 기준 소스로 복원했고, 진행 중이던 고지·법률 페이지·카드 제한 개선은 `releases/v0.2.0`으로 이동했다. **운영 서버에 접속·수정·재시작하지 않았으며 Azure 작업·Git commit/push/merge·실제 유료 API 호출을 하지 않았다.**

## 기존 변경 보존

- 이동 직전 릴리스 소스 69개를 v0.2.0으로 복사한 뒤 v0.1.7의 추적 파일을 저장소 HEAD와 같게 복원했다. 새로 추가했던 법률/제한 소스도 새 릴리스에 보존했다. [보존 목록과 해시](separation.json), [이동 전 추적 파일 변경 패치](pre-separation-tracked.patch)가 있다.
- 이전 [Production 심사 정비 보고서](../riot-production-review-2026-10-28/README.md), [카드 권한 감사](../riot-production-review-2026-10-28/card-source-audit.md), 수집 캐시 집계와 운영자 입력 템플릿을 유지했다. 이전 보고서의 v0.1.7 반영 설명은 당시 로컬 작업 기록이며, 최종 적용 대상은 이 보고서에 따른 v0.2.0이다.
- 테스트 도우미·CI·ignore 변경은 공용 개발 지원 파일로 보존했다. v0.1.7 런타임 소스·공유 자료/포인터/키/사용자 DB는 v0.2.0 개발용으로 변경하지 않았다.

| 수집/버전 자동 전환 | 기존 동작 유지 | 기존 수집기 자동 시작 비활성, mock preview도 자동 활성화하지 않음 |

## 구현한 보완

1. **카드 접근 제한:** 원 파일이나 권한 플래그를 변경하지 않고 서버 요청별 카탈로그 뷰를 만든다. 기본 `restricted` 또는 잘못된 설정이면 카드 표시를 허용하지 않는다. `verified-only`에서도 검증된 출처·본문·버전·display 조건을 확인하고 모델에는 modelInput 조건까지 적용한다. 이전 프로토타입 예외로 외부 미확인 카드를 공개하거나 모델 입력에 넣을 수 없다.
2. **우회 경로:** 목록/상세/자동 인식/이미지/질문 모델 입력/번역 용어집에 같은 뷰를 적용한다. 클라이언트가 카드 ID·제외 목록을 조작해도 차단된다. 이전 정책의 응답 재전송은 409로 거절하며, 예전 카드명 번역 키는 현재 용어집과 다시 대조한다. 원 사용자 기록을 삭제·수정해서 차단하는 방식이 아니다.
3. **기존 기능 보존:** 미확인 카드가 인식된 질문은 AI 판정을 보류하지만 규칙·저지 사례 근거와 제보를 제공한다. 일반 규칙 질문의 AI 경로, 허용된 개발 카드 검색/선택, 번역·오류·관리 기능을 모의 응답으로 검증했다. 원 DB 스키마나 v0.1.7의 암호화 키를 마이그레이션하지 않았다.
4. **개발 격리:** 운영 공유 데이터 루트, 마커 없는 루트, 외부 운영 자료를 가리키는 내부 링크를 DB 개설 전에 거절한다. 준비 명령은 새 빈 디렉터리만 사용하며 기존 포인터를 덮어쓰지 않는다. 개발 관리 화면은 공개 터널 설정을 거절한다.
5. **공식 API 준비:** 모의 카드 수집→기존 카드 스키마 변환→영어 보존/번역 출처 기록→미출시 표시→preview 파일 작성 경로를 만들었다. 실제 adapter는 명시적 활성화·승인 앱 참조·검토된 endpoint/매퍼·키가 모두 있어야 호출할 수 있다. **실제 Riot endpoint와 응답 계약은 아직 미확정이므로 실제 연동 완료로 보고하지 않는다.**
6. **개인정보 문서:** 기본 모의 환경과 향후 실서비스 전송을 구분하고, 실제 동의 체크박스/전용 동의 이력 저장이 없다는 점, 출처 캐시가 별도 평문 SQLite/JSON이라는 점을 보완했다. 운영자 성명·법적 명칭·연락처·권리 창구·처리 근거·외부 계약·국외 이전·로그/백업 조건·시행일은 만들지 않았다. [운영자 입력 템플릿](../riot-predeploy-hardening-2026-10-28/operator-privacy-inputs.json)은 모두 미확정 null이다.

최종 결과는 [서버/통합 TAP](regression.tap), [브라우저 TAP](e2e.tap), [원본 v0.1.7 회귀 TAP](legacy-regression.tap), [검증 메타데이터](validation.json)에 기록한다.

- v0.2.0 Node 회귀·통합 **28/28 통과**: 기존 판정 11, 기존 법률/운영 통합 3, 카드 정책·재전송/번역 우회·자료 reload 9, 환경 격리·어댑터/번역·분리 게이트웨이 5.
- v0.2.0 브라우저 **12/12 통과**: 기존 사용자 흐름 5, 법률/모바일/무스크립트/제보/PWA 5, 미확인 카드 제한 및 합성·미출시 표시 2.
- v0.1.7 원본 회귀 **11/11 통과**, 런타임 소스 차이 없음. 라이브 서비스에 질문을 보낸 검사가 아니라 별도 임시 서버 검사다.
- 환경: Node 24.19.0, Playwright 1.62.1, 시스템 Chromium 154.0.8037.57. PC 1280px, 모바일 390/320px. 실패·skip·todo 0. 실제 유료 API·Riot 호출 0.
- 첫 신규 검사 1건은 테스트가 JSON의 이스케이프된 줄바꿈을 원문 문자열과 직접 비교해 실패했다. 모델 입력의 카드 JSON을 파싱해 영문 본문과 비교하도록 고쳤고 원문 전송 계약은 유지했다. 초기 결과는 `regression-initial.tap`에 보존했다.
- 고정 규칙/역사적 카드 회귀 fixture는 출처가 있는 기존 테스트 자료이며 실제 수집 후보로 게시하지 않는다. 권한 플래그가 필요한 테스트는 임시 메모리/DB에 **합성 mock 출처**를 부여한다. 실제 카드 파일·권한·운영 키는 바꾸지 않는다. 원본 v0.1.7 테스트의 예전 스키마 호환용 권한 오버레이도 테스트 안에서만 쓴다.
- 실제 공식 API 명세/실제 데이터 정확도, OpenAI 의미 추론·과금, 실기기 Safari/Android, 공개 HTTPS/터널·Azure, 동일 origin PWA 전환/롤백, 실운영 트래픽 전환은 아직 검증하지 않았다.

## 수집 DB와 권한 문제

별도 [수집 캐시·Git 처리 보고서](source-cache-and-git.md)에 세 SQLite 파일의 성격, 비밀값 없는 집계, 디스크 파일을 유지하는 `git rm --cached` 절차와 이력 정리 한계를 적었다. 인덱스 제외·커밋·push는 실행하지 않았다.

기존 1,527개 카드의 권한 미확인 문제는 v0.1.7에 그대로 남아 있다. 사용자 지시에 따라 라이브를 수정하지 않았고 이를 v0.2.0의 공식 데이터로 가져오지 않았다. 새 제한 기능은 향후 v0.2.0에 적용될 기능이며 기존 운영의 법적 문제를 소급 해결하지 않는다.

## 해결 시점별 남은 일

| 시점 | 필요한 일 |
|---|---|
| 심사/공개 전 필수 | 운영자·연락처·권리 창구, 처리 근거/동의 방식, 외부 계약·보관/이전과 백업 삭제 절차 확정. 참고형 AI 및 자산 사용 범위를 Riot에 설명/확인. 합성/실제 자료를 구분한 심사 데모 준비. Git 캐시 추적 제외와 배포 패키지 검사 |
| API 승인 후 가능한 구현 | 실제 공식 endpoint/DTO·언어/정오표/미출시/rate-limit 계약에 맞춘 매퍼와 수집·검증, 실제 공식 카드·이미지·번역 후보 생성. 카드별 표시/모델 전송 권한 검토. 운영자 승인에 따른 staging 연결 |
| 실제 배포 전 필수 | 실제 데이터 검증, HTTPS/보안/부하/장애·PWA 전환/롤백 시험, 운영 문서 완성, 최종 코드/자료 버전 고정, 사용자의 명시적 배포 승인 |

API 승인이 나더라도 위 절차나 운영 전환을 자동 실행하지 않는다. [배포·롤백 계획](deployment-and-rollback.md)은 별도 데이터 루트·새 키·독립 프로세스/라우팅을 유지하고 v0.1.7로 되돌릴 때 DB 복원/역마이그레이션이 필요 없도록 설계했다.

## 수정 파일 범위

- `releases/v0.2.0/`: 이전 소스 기반 별도 릴리스 전체, 고지/법률 UI, 카드 접근 정책, 환경/외부 서비스 격리, Riot 모의 어댑터·변환/번역, 합성 fixture, 개발 준비/시작/preview 명령, 설정 예시, ready=false 명세와 안내.
- `tests/`: 기본 대상을 v0.2.0으로 변경, 격리/정책/어댑터 검사와 원본 v0.1.7 별도 실행 명령 추가, 시스템 브라우저/별도 결과 폴더 지원 유지.
- `.github/workflows/rules-tests.yml`: v0.2.0과 v0.1.7 호환 검사를 분리해 실행. 실제 GitHub 실행은 하지 않음.
- `experiments/unified-rulings/.gitignore`: 새 개발 루트·로컬 설정·런타임 DB/키 제외.
- `artifacts/`: 이전 작업 보존, 이번 분리·검증·법적/운영 입력·배포/롤백 기록. v0.1.7 런타임 파일은 수정 목록에 없다.
