## 관리자 사용 방법

기존 `Open-Manager.cmd`로 관리 화면을 열거나 열린 관리 페이지를 새로고침 → **오류·룰링 제보**.

1. 기본 목록은 미해결 제보. 상태/유형/제보·요청 번호 일부로 필터링한다. 목록은 API가 제공하는 최근200건 범위이며 전체 DB 통계로 표시하지 않는다.
2. 제보를 선택하면 문제 설명/기대 답변, 당시 질문·답변, 연결 카드, 인용 및 검색 근거, 처리 기록, 상태·메모 이력을 본다.
3. 규칙/사례는 접이식이며 ‘인용’과 ‘검색만’을 구분한다. 당시 보존된 본문/번역/사례 비교/상위 조항을 표시하고 현재 자료로 임의 대체하지 않는다.
4. 자료·카드·검색·프롬프트 버전, 모델 오류·토큰·처리 시간, 필수 조항 누락과 후보 선정 이유는 기록에 있는 값만 표시한다. 모델 내부 사고 과정은 수집하거나 표시하지 않는다.
5. 원인을 확인한 뒤 처리 상태와 메모를 저장한다. 다른 제보를 열 때 미저장 입력이 있으면 확인한다. 읽기/저장 중 중복 선택을 막고 기존 이력을 보존한다.
6. 읽기 쉬운 TXT 또는 원본 JSON으로 내보낼 수 있다. TXT에는 접힌 상세 본문도 포함한다. 저장 전 메모는 내보내지 않는다. 파일을 공개하지 않는다.

제보가 없어도 정확성을 검증한 것으로 표시하지 않는다. 제보 본문은 데이터로만 표시하며 HTML이나 자동 수정 지시로 실행하지 않는다. 링크는 HTTP/HTTPS만 허용한다. 연결 기록이 없거나 만료된 제보는 자료 없음으로 표시한다.

## 사용자 화면

- ‘내 제보 상태’ 버튼/목록/조회 코드 제거. 오류·버그 제보와 해당 답변 제보 기능, 접수 번호 안내는 유지했다. 기존 API는 호환성을 위해 유지한다.
- 사진 첨부/미리보기/전송 코드 제거. 서버는 사진이 포함된 요청을 질문 저장/검색/AI 호출 전에 거절한다. 오래 열린 화면에는 사진 제거/새로고침 안내가 나온다.
- 사진 관련 고지 문구를 현재 텍스트 전용 동작에 맞췄다. 카드 그림과 카드 자동완성은 유지한다.
- 사용자 페이지 새로고침, 이전 UI가 남으면 Ctrl+F5. 작성 중 질문은 강제로 새로고침시키지 않는다.
