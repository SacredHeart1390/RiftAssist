# 관리자 운영 요약 적용

2026-10-22 10:21 KST. 사용자 부재 중 직접 계정 조작 없이 진행할 개선을 선택하여 구현했다.

## 반영된 기능

- 기존 관리 페이지에 운영 요약 추가: 실행 앱 버전, 진행 중 HTTP 요청, 오늘 AI 호출 시도, 전체 보관 제보 중 미해결 개수, 공식 규칙/Q&A 확인 시각과 본문 수집량, 카드 수동 갱신 상태.
- 답변/새 번역의 일일 사용량·남은 횟수·확인된 토큰을 표시. 한도80%/한도 도달, 입력 사용량 미확인, 자료 확인 지연/수집 오류/수집기 기록 지연 안내. 서비스나 한도 설정을 자동 변경하지 않는다.
- 운영 상태10초/자료·제보 목록60초 자동 조회. 숨긴 탭에서는 조회하지 않고 돌아오면 갱신. 인증 만료 시 자동 조회 중단, 읽기 요청15초 제한, 실패 시 마지막 확인값과 실패 안내 표시.
- KST 날짜 표시. 자동 조회 시 자료/앱 버전 선택과 작성 중인 제보 메모 유지. 자료 선택 또는 활성 자료 버전 변경 시 검토 확인란 해제.
- 질문·답변·제보 본문과 인증 정보를 제외한 운영 요약 JSON 저장. 기존 제보 TXT/JSON 내보내기는 유지.
- 수동 카드 갱신 정책을 장애로 표시하지 않도록 문구를 정리했다. 운영 알림은 관리 화면을 열고 있을 때만 확인되며 외부 알림/상시 모니터링 서비스가 아니다.

- 적용 전후 관리자PID22164, 앱PID24624/포트3011/v0.1.4, 공개 게이트웨이, 터널connected, 공개 주소가 같았다. 공개 주소는 `https://mustang-science-violation-declaration.trycloudflare.com`이다. 이 주소는 해당 시점의 임시 주소이며 이후 재시작 시 바뀔 수 있다.
- 서버/터널/수집기를 재시작하지 않았다. 공개 앱, AI 모델/키/한도, 운영 DB 구조, 자료 버전 선택도 변경하지 않았다. 이 작업에서 생성 AI 호출0.
