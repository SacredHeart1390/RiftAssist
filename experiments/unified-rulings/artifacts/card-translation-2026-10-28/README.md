# v0.2.0 한국어 카드 번역 엔진 검증 보고서

2026-10-28, `feature/riot-api-v0.2`에서 수행했다. 기존 Draft PR #1을 유지하며 v0.1.7·공유 운영 자료를 변경하지 않았다. 실제 Riot/OpenAI 호출 없이 합성 카드·모의 응답으로 구현했다. `app-release.json`은 `ready: false`다.

## 구현 범위

- 공식 한국어 우선: 매퍼/주입된 locale 조회 결과의 출처·대응 영어 버전을 검사한다. 필드 누락이나 조회 실패를 공식 번역 부재로 추측하지 않으며 AI 호출을 차단한다. 공식 한국어 전체/이름/키워드를 우선하고 필드별 출처를 기록한다.
- AI 공급자 경계: 구조화된 문장별 번역 계약·명시적 활성화·승인 참조·호출 예산·시간 제한을 제공한다. 실제 OpenAI 번역 클라이언트는 구현하지 않았다. CLI는 항상 모의 공급자만 사용한다.
- 이름/효과/키워드/비용/능력치/기호와 영어 원문을 분리한다. 공급자·모델·생성 시각·원문 해시/버전·용어집/검사 버전·검증/관리자 검토 상태·필드별 공식 출처를 저장한다.
- 용어집은 정렬된 공식 규칙 용어를 기본으로 하고, 권한·버전·원문 근거·검토 참조가 있는 공식 카드 매핑을 우선할 수 있다. 실제 한국어판 카드 용어·문체 예제 확보/보정은 승인 후 작업이다. 리프트나루 번역을 공식 용어집으로 사용하지 않았다.
- 숫자·기호·문장 순서·비용/능력치·부정·대상/소유·조건·선택/강제·타이밍·키워드·문장 내 수량 교환을 자동 검사한다. 오류는 차단하고 불확실성은 관리자 검토로 보낸다. 정상 번역도 자동 승인하지 않는다.
- 영속 캐시·병렬 잠금으로 동일 영어의 불필요한 호출을 막는다. 원문 버전만 달라져도 영어 내용이 같으면 재사용한다. 오류/시간 초과도 캐시하고 손상/저장 실패 후 자동 재호출하지 않는다.
- 후속 공식 번역은 교체 후보를 생성하며 기존 번역/영어/이전 후보와 변경 이력을 보존한다. 기존 미확인 한국어의 출처를 공식/AI로 추정하지 않는다.
- 공식 공개 근거가 있는 미발매 카드만 수집·변환하도록 검사하고 프리뷰/비공식 번역 표시를 유지한다.
- 새 번역·knowledge 후보만 생성하고 규칙·저지 사례는 기준 릴리스와 동일하게 복사한다. 활성 포인터를 쓰지 않으며 기준 릴리스가 바뀐 후보의 수동 활성화도 차단한다.
- 공개 카드 API에서 검토 전 후보·과거 이력을 제외한다. 승인 한국어 이름 검색과 명확한 비공식 AI 표시, 영어/한국어 분리 표시를 지원한다. AI 판정은 영어 원문을 계속 근거 입력으로 사용한다.
- 카드 번역 캐시·후보 및 향후 공급자 연결의 실제 동작/미확정 사항을 개인정보 처리방침에 한·영으로 추가했다. 운영자 정보나 동의·허가를 임의로 작성하지 않았다.

주요 수정 파일은 `releases/v0.2.0/src/card-translation*.js`, `official-card-locales.js`, `card-publication.js`, `mock-card-translator.js`, `cards.js`, `riot-adapter.js`, `riot-converter.js`, `card-access.js`, `knowledge-releases.js`, `server.js`, 미리보기 스크립트/설정 예시, 카드 UI·개인정보 처리방침과 공유 테스트다. 상세 계약은 [card-translation.md](../../releases/v0.2.0/card-translation.md)에 있다.

## 보존·Git 검사

- `baseline.json`과 `preservation.json`: v0.1.7 추적 파일 **65개가 원격 main과 동일**하다. 공유 `knowledge-releases/active.json`, 활성 manifest/카드/규칙/저지 사례와 추적 중인 `content.sqlite`, `content.sqlite-wal`, `content.sqlite-shm`의 해시가 작업 전과 동일하다.
- 운영 DB·암호화 키·사용자 기록은 열거나 수정하지 않았다. Git 추적 제외·기존 자료 삭제/교체·main 병합·Azure 작업·라이브 전환은 하지 않는다.
- 새 개발 릴리스 manifest는 **89개 파일 해시**를 기록하고 `ready: false`를 유지한다.
- 경로·DB 형식·API 토큰/개인키/자격증명 리터럴 검사로 실제 staged blob도 확인한다. 정확한 비기능 테스트 문자열 4개만 예외로 허용한다. 이 검사는 모든 종류의 비밀정보나 Git 전체 이력을 증명하지 않는다. 기존 추적 DB의 안전한 제외/이력 정리는 기존 [별도 계획](../riot-v0.2.0-2026-10-28/source-cache-and-git.md)을 유지한다.

## 남은 확인과 정확성 한계

**실제 연동 전 필수:** Riot 승인 및 텍스트·번역·제3자 AI 입력·저장/재배포·이미지 권한/출처 조건 확인, 실제 DTO/locale/버전/공개 상태 매퍼, 공식 한국어 조회기, 실제 번역 공급자 어댑터와 안전한 키 주입·계약/보관/국외 이전·비용 한도, 허용된 공식 한국어 카드 용어/문체 예제와 한영 골든 테스트가 필요하다. API 키를 찾거나 승인됐다는 이유로 자동 활성화하지 않는다.

**관리자 검토 필수:** 자동 검사는 휴리스틱이며 의미 등가성을 증명하지 못한다. 복잡한 조건/예외·대명사·대상 수·효과 범위/지속 시간·비용과 효과의 관계·정오표·새 키워드·공식 번역 경고·후속 교체는 한영 규칙 검토자가 확인해야 한다. 실제 모델의 번역 품질/환각률은 아직 측정하지 않았다. 공식 번역이 있으면 이를 AI로 재작성하지 않는다.

검토는 JSON 큐와 순수 `reviewTranslation` 함수로 제공한다. 전용 관리자 번역 검토 화면과 승인 복사본을 별도 후보에 저장하는 운영자 도구는 추가 작업이다. 새 후보의 카드 범위/누락도 확인해야 한다. 공급자 오류/시간 초과/잔류 잠금은 과금 상태를 조사한 뒤 운영자가 명시적으로 재시도한다. 캐시/후보 자동 만료·운영 보관 정책도 정해야 한다.

기존 리프트나루 1,527개 카드의 권한은 해결되지 않았다. 삭제하거나 공식 Riot 데이터로 옮기지 않았다. 운영자 연락처·법적 정보·동의 방식 등 기존 미확정 사항도 그대로 남아 있다. 실제 데이터 검증·보안/장애/실기기 검사를 통과한 뒤 별도 사용자 배포 승인을 받아야 하며, [기존 분리 배포/롤백 계획](../riot-v0.2.0-2026-10-28/deployment-and-rollback.md)을 적용한다.
