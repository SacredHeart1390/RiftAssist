# 공식 용어·카드 입력·검색 표시 — v0.1.6

2026-10-23 09:24 KST 적용. 개발 기준 `releases/v0.1.6/`. 기존 v0.1.5/원본/운영 데이터 보존.

## 1. 공식 한국어 용어

- 공식 한국어 규칙 허브, 최신 핵심 규칙 링크, 공식 플레이 방법 페이지 및 공식 FAQ를 확인했다. 공식 웹 PDF 도구는 한국어 PDF의 크기 때문에 본문 열기에 실패했으므로, 링크가 일치하는 기존 수집본의 영어/한국어 조항과 버전·출처를 사용했다. 오래된 가이드/FAQ의 판정을 새 판정 근거로 추가하지 않았다.
- 공식 한영 문서 날짜가 일치하는 조항의 짧은 표제와 확인된 정의에서 용어표를 구성한다. 현재 추출205항목(복수형·별칭 포함)의 출처/조항/버전은 `official-terms.json`. 이후 자료 교체 시 해당 자료의 공식 한국어 표기에서 다시 구성한다.
- 주요 표기: Trash 폐기장, Hand 손, Showdown 결전, Combat 전투, Channel 전개, Exhaust 탈진, Burn Out 소진, Ability 스킬, Resolve 처리. 턴 단계는 각성·개시·전개·뽑기·주요·종료.
- 한국어 답변에는 날짜가 일치하는 공식 한국어 조항을 우선 제공한다. 답변과 사례 번역이 같은 용어표를 사용한다. 반드시 필요한 용어를 먼저 넣고 문맥에 해당하는 용어를 더해 최대90항목으로 제한, 입력 예산에 포함한다.
- 명확한 음역/오역만 출력에서 정리하고, 카드명·숫자·기호·원문 자료는 보존한다. 특히 ‘소진’을 일괄 ‘탈진’으로 바꾸지 않는다. 원문에 없는 판정을 번역 과정에서 수정하지 않는다.
- 번역 프롬프트/캐시 버전 변경. 새 요청은 이전 용어의 캐시를 재사용하지 않으며, 미리 전체 번역을 돌리지 않는다. 구 화면에서 요청한 이전 캐시는 명확한 용어 변형만 읽을 때 정리한다. 과거 답변 로그나 원문 PDF는 수정하지 않는다.

## 2. Tab 선택

- 원인 코드: 한글 조합 상태에서 Tab까지 먼저 반환하던 처리, 후보 표시 시 활성 항목이 -1인 상태, 조합 종료 후 목록/선택 초기화.
- 후보가 표시되면 첫 후보를 기본 선택. 위/아래 이동 → Tab 확정. Tab을 조합 상태 검사보다 먼저 처리하고 기본 포커스 이동을 막는다. 조합 중 확정은 입력을 마무리한 뒤 같은 텍스트일 때 선택한다.
- Enter는 줄바꿈/한글 확정, Shift+Tab과 후보 없는 Tab은 일반 이동 유지. 텍스트 변경/요청 취소 시 오래된 카드 선택을 적용하지 않는다. 자동 연결과 수동 선택이 겹치는 표시도 중복 제거.

## 3. 카드명 재인식

- 같은 브라우저 탭에서 선택 카드 ID만 최대64개 기억한다. 질문 이력·카드 본문을 브라우저 저장소에 추가하지 않는다. 새 질문/새로고침에도 해당 탭의 선택을 참조하며, 탭을 닫으면 일반적으로 사라진다.
- 입력 중 260ms 지연 후 서버 카드 목록에서 이름을 확인하고, 일치하는 모든 등장 위치를 강조·연결한다. 이름이 명확하면 처음 입력한 카드도 연결할 수 있다. 같은 이름의 다른 카드/서로 다른 효과는 임의 선택하지 않으며 이전 선택 또는 명시적 선택을 사용한다.
- 요청마다 최신 서버 카드 자료를 읽는다. 브라우저가 보낸 카드 본문을 신뢰하거나 모델 기억으로 효과를 추정하지 않는다. 더 긴 전체 이름을 우선해 일부 단어가 다른 카드로 중복 연결되지 않게 한다.
- 카드 조회 전용 `/api/cards/resolve`는 AI를 호출하거나 질문 로그를 생성하지 않는다. 최종 제출 때도 동일한 조회를 수행하므로 입력 중 조회가 늦거나 취소돼도 가능한 명확한 이름을 다시 연결한다. 기존8개 카드 제한 유지. ×로 연결 해제한 이름은 현재 질문에서 자동 재연결하지 않는다.

## 4. 진행 표시

- 제출 즉시 버튼 ‘검색 중…’/‘Searching…’ 및 회전 표시. 아래에 ‘규칙과 사례를 찾아 답변을 작성하고 있습니다.’ 표시. 실제 단계를 모르는 상태에서 진행률이나 특정 단계 완료를 표시하지 않는다.
- 중복 제출 방지, 성공/오류 모두 표시 해제. 늦게 도착한 최초 상태 조회가 진행 중 버튼을 다시 활성화하지 않도록 수정. 화면 읽기 프로그램용 상태 알림 및 움직임 줄이기 설정 반영.

## 배포 및 확인 범위

- 변경 JS8파일 문법 검사, 코드 검토, 운영 작업서버 준비 확인, 제공 정적7파일 해시 일치 확인. 기능 테스트 스위트/실제 키보드 조작 테스트/유료 AI 생성·번역 호출은 하지 않았다. `review.testsRun=false`, 유료 호출0.
- 운영 작업서버3012→3011 전환, 게이트웨이3001·관리자3100·터널 유지. 전환 전후 조회HTTP200. 공개 주소 `acid-foods-strict-publishers.trycloudflare.com` 유지, 상태 v0.1.6.
- 새 파일 이름 `app-ui5.js`, `card-composer-ui3.js`, `styles-ui5.css`와 새 서비스 워커 캐시 사용. 이전 파일도 보존하여 이미 열린 화면 호환성을 유지한다. 새 입력 동작은 Ctrl+F5로 새 화면을 불러와야 한다.
- `changed-files.json`, `deployment.json`, `public-health.json`에 적용 증거 기록. 추후 실사용 피드백에 따라 한글 IME/카드명 모호성/AI 표현을 추가 조정한다. 용어표가 모든 생성 문장의 완전한 정확성을 보증하는 것은 아니다.
