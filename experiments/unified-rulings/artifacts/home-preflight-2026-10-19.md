# 집 PC 운영 기능 점검 기록

2026-10-19. 통합본 `experiments/unified-rulings` 대상. 원본 앱3000 보존.

## 수정과 확인

- 중단 지점의 질문 처리 HTTP500 원인: SQLite 요청 INSERT의 열/값 개수 불일치. 명시적 9개 열·9개 값으로 수정.
- `scripts/check-home.cjs`: **56개 확인 통과, 종료 코드0**. 외부 요청0, 유료 모델 호출0. Node24.19.0 사용.
- 격리 자료: `tmp/home-check-1792408912446`. 임시 규칙 자료와 외부 fetch 대체를 사용했으며 실제 API 키를 테스트 서버에 전달하지 않았다.
- 확인 범위: JS 구문, 허용 공개 주소 변경/해제, 일일 호출 예약·토큰 집계, 관리 인증/Host/Origin/프록시 헤더 차단, 앱 시작·중지·재시작, 비공개 파일/관리 경로 차단, 질문 저장·중복 처리, 제보 접수·중복 처리·다른 익명 세션 접근 차단, 관리자 상세·상태 이력, 백업 DB/키 복원·복호화.
- Quick Tunnel은 가짜 자식 프로세스로 명령 인수·앱 포트 대상·URL 추출/유사 도메인 거부를 확인했다. 실제 파일이 없으면 시작을 거부하는 관리자 흐름도 확인했다. 실제 Cloudflare 통신은 하지 않았다.

## 실제 통합본 시작

- `scripts/open-manager.ps1 -NoBrowser`로 관리 프로그램 시작. 숨김 실행. 이어서 로컬 관리자 API로 앱3001 시작.
- 반환 상태: manager=true, appRunning=true, publicOrigin="", tunnel=off, version=0.1.1, aiConfigured=true, aiEnabled=true, 공식 규칙3471, 카드1527.
- 브라우저에서 새로고침 후 리프트어시 v0.1.1·보유 기간 고지·제보 버튼/모달 표시 확인. 질문과 제보 제출은 하지 않았다. 이번 실제 시작 단계의 유료 호출0.
- 제보 모달 확인 이미지: [report-ui-2026-10-19.jpg](report-ui-2026-10-19.jpg).

## 확인하지 않은 범위

- 실제 cloudflared 실행 인수 호환성·Cloudflare 연결·외부 HTTPS/휴대폰 접속.
- 수정본의 유료 답변/번역 실호출, 저징 정확도, 사진 정확도, 모바일 화면.
- 보존 기간의 시간 경과/정리 전 과정, 실제 운영 DB 장애 복구, Windows 재부팅 후 자동 시작.

관리자의 일일 호출 한도는 달러 결제 상한이 아니다. 본 점검 통과를 실제 룰링 정확도나 인터넷 운영 검증으로 해석하지 않는다.
