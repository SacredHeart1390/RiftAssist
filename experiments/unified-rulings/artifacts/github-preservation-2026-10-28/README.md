## 커밋 안전성 검사

[검사 스크립트](inspect-commit.py)는 명시한 경로 범위의 후보 파일과 Git 인덱스의 실제 staged blob을 검사한다. 경로상 private/개발 런타임/SSH/운영 지식 포인터/DB/키/환경 파일, SQLite 매직 값, 예상하지 않은 바이너리·심볼릭 링크를 거절하고 API 토큰·개인키·URL 자격증명·민감 필드의 리터럴 패턴을 확인한다. 값 자체를 출력하지 않는다. 네 가지 정확한 비기능 테스트 문자열만 모의 자격증명으로 허용한다.

커밋 후보 검사에서 민감정보 패턴 검출 0건을 확인했고, 커밋 직전 staged blob 검사도 통과 조건으로 삼는다. 이 검사는 Git 전체 이력이나 모든 유형의 비밀·개인정보 부재를 보장하는 완전한 보안 감사가 아니다. 14개 PNG는 고정 fixture·모의 API로 생성한 시험 화면이며 운영 사용자·관리자 인증 화면이 아니다.

이미 Git에서 추적 중인 `content.sqlite`, `content.sqlite-wal`, `content.sqlite-shm`은 이번 commit/PR의 변경·삭제·추적 제외에 포함하지 않는다. 이전 커밋에 존재하는 blob 자체가 이번 작업으로 사라지는 것은 아니다. 별도 안전한 `git rm --cached` 검토 절차와 이력 한계는 [수집 캐시·Git 보고서](../riot-v0.2.0-2026-10-28/source-cache-and-git.md)에 있다.

## PR에서 명시할 상태

- v0.2.0은 `ready=false`, 기본 외부 서비스 mock, 미확인 카드 기본 제한이다. 고지·한/영 법률 페이지·격리된 DB/키/쿠키·모의 수집/변환/번역과 수동 전환 준비를 보존한다.
- Riot Production API 승인은 대기 상태다. 실제 승인 범위·endpoint/응답 계약 확인, 실제 매퍼 구현과 공식 데이터 검증, 카드별 표시·AI 전송·번역/이미지 권한 확인이 필요하다.
- 운영자 법적 정보·연락처·권리 창구, 처리 근거/동의 방식, 외부 계약·국외 이전, 로그/백업 보관·삭제 조건은 미확정이다. 동의나 허가를 지어내지 않았다.
- 기존 v0.1.7의 RiftNaru 카드 1,527개 권한 문제는 미해결이며, 이들을 v0.2.0 공식 자료로 옮기지 않았다. 원본 운영 자료는 유지한다.
- 실제 공개 HTTPS·실기기·PWA 버전 전환/롤백과 실제 데이터·운영 연결 검증 및 사용자의 별도 배포 승인이 필요하다. API 승인만으로 자동 배포하지 않는다.
- **main 병합, PR 자동 병합, Azure 운영 수정·재시작·배포, 운영 데이터/카드 삭제·교체, 유료 API 호출 금지**를 PR에 명시한다. 이번 PR은 배포 준비가 끝나지 않은 개발 결과를 보존·검토하기 위한 Draft로 만든다.
