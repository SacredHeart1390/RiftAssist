## 변경

- 일반 시작/중지/재시작·설정·제보 변경과 카드 결정/후보 구성은 짧은 예/아니요 확인으로 통일했다. 입력/체크박스가 없고 기본 선택은 아니요다. 취소하면 요청하지 않는다.
- 사유는 고정 작업명·개발 GUID/제보 ID/상태/버전으로 자동 생성한다. 제보 메모·본문·SSH 프로필의 민감 필드를 복사하지 않는다. 실제 Node 카드/관리 감사에서 생성된 사유가 남는지 검사한다. 선택적 제보 메모는 유지한다.
- 최종 활성화/롤백·개발 버전 적용·DB/키 백업은 확인 문구/체크를 유지하고 사유는 자동 생성한다. 삭제·운영 복원·배포를 추가하지 않는다. 내부 권한·HMAC/UTF-8·nonce·중복 ID·revision·경고·감사·잠금과 운영 차단은 변경하지 않았다.
- 조회·새로고침은 확인창이 없다. SSH는 사용자의 조회 버튼에서만 실행하며 반복 승인 체크/문구를 제거했다. 앱 시작/설정 저장/불러오기/모드 전환으로 접속하지 않는다. 고정 읽기 전용 명령·호스트 키 검증·인증·25초 제한·취소는 기존 엔진을 재사용한다.
- CPU/RAM/디스크/가동시간/웹사이트·앱 HTTP/systemd를 6개 카드로 표시한다. 실패·이전 값·미조회·모의 값을 구분한다. 설정 필드/찾아보기/저장 상태·불러오기를 정리하고 잘못된 SSH 포트는 저장과 조회 전에 차단한다. 연결 오류는 원시 stderr 대신 쉬운 설명으로 표시한다.
